طريقة رفع الموقع مجاناً مدى الحياة

1 إنشاء مستودع GitHub

قم بإنشاء مستودع جديد (Repository) على موقع GitHub باسم مثلاً my-apps.

2 حفظ الملف باسم index.html

احفظ هذا الكود كاملاً في ملف باسم index.html وقم برفعه إلى المستودع.

3 رفع برامجك الخاصة (.exe / .zip)

قم برفع برامجك إلى خيار Releases في صفحة GitHub للحصول على روابط تنزيل مباشرة وسريعة، ثم ضع هذه الروابط في القائمة أسفل الكود.

4 تفعيل GitHub Pages

اذهب إلى Settings -> Pages في مستودعك، واختر فرع main ثم انقر Save. سيعطيك الموقع رابطاً مجانياً يعمل مدى الحياة!
